v1.7.73 · 主副 API 独立分工

设置 → 副 API → 从已保存预设载入。复制预设当时的主连接作为独立副本，原预设之后修改、删除或切换主预设都不会影响它。

聊天回复、观看推进/重抽用主 API；记忆总结、人物/行程/购物/生活事件等其他生成用副 API。副 API 未配置完整或失败时不回退到主 API。语音/绘图专用接口保持原设置。

完整记忆和历史条数保持不变；只去掉请求里的完全相同副本，让实际知情者引用同一份完整私聊/事件原文，不删本机数据。

独立生活入口仍在底部「我」→「生活与主动联系」。

  • 角色与角色、角色与NPC、NPC与NPC均可建立私聊、主动联系；可选择任一方身份发送并让对方继续。
  • 新增持续状态、分对象信任、约定/待办、明确规矩与本人知情记录。到期只待核实，不自动认定违约。
  • 行程随空间时间推进；临时联系可提出行程调整，确认后执行，不覆盖冲突或刚修改的安排。
  • 私聊只有参与者获得相应记忆。作者观看不等于其他角色知情；普通群聊、观看群聊和私聊均接入。

主动联系默认关闭，请按需开启并设置空间分钟间隔，使用已保存的副 API，可能产生相应费用。仅在网页打开、可见且空闲时运行；编辑内容时暂停，不会关闭网页后后台调用，也不会跳时后补刷大量消息。生成中可随时点浮层或页面内的「停止」。所有生活资料按空间隔离、保存在本站IndexedDB，并随备份导出。
