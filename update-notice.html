v1.7.74 · 完整上下文统计与发送范围

聊天设置不再把基础资料估算当成完整输入总量。新增「上次完整请求」分类统计和「上次 API 实际输入」；接口未返回用量会明确标注，不额外调用 API 估算。

不再每轮展开所有场外联系人的人设、行踪和关系证据。保留关系称谓；当前成员完整人设不重复，提及的联系人完整档案只发送一份。没有相关订单时不附带整份订单操作说明。

完整聊天记忆、总结、短期记忆条数及手动勾选的挂载聊天保留；本机档案、关系、证据和历史均不删除。统计按空间与聊天独立保存，仅存数字，不复制私人原文或密钥。

主副 API 分工及独立副 API 预设保持不变。完整文本仍是估算，图片/模型分词与服务商附加内容会产生差异，以接口返回用量和账单为准；补发或其他辅助调用也可能另外计费。
