v1.7.80 · 第三方生图模型选择修复

生图模型改为独立下拉列表，不再依赖输入框的自动补全提示。拉取成功后点击“生图模型列表”即可选择，自动填入并保存当前生图模型；仍可手动填写模型名称。

拉取不会擅自切换已保存的模型，也不会生成图片。切换接口、密钥、接口类型或载入预设时清除旧模型选项，避免误用另一家服务的列表；重新打开页面保留已选模型，不自动拉取或产生生图费用。

修复离线缓存接管所有 GET 请求的问题。127.0.0.1／localhost、本地网络和其他 API 请求现在由页面直接发起，不读取缓存模型列表，不交给后台缓存线程。主、副、生图模型拉取均适用。

本机 API 请求增加回环地址标注，Edge 如提示访问本地网络／本机服务，请允许当前 GitHub 网站；糯叽机的授权不自动适用于本站。仍需本地服务允许跨域，修复不绕过浏览器安全限制，也不检测或禁止 VPN。

升级只更新 EPhone 静态网页缓存，保留聊天、钱包、API 预设及其他网站缓存。无需清除网站数据；不增加 API 探测或付费请求重试。

设置 → API 设置 → 图像生成，当前生图服务可选“第三方生图 API”。可载入已有 API 预设，选择／填写生图模型，也可另存、更新或删除独立生图预设。生图地址、密钥、模型独立保存，不随主／副 API 切换，不随来源预设修改。

支持常见图片接口、对话生图接口与 Gemini 原生生图接口。自动判断只决定本次使用的协议，不会失败后换接口重试。服务商必须实际支持所选生图模型与协议；网页直连还需其允许跨域。

私聊、普通群聊、观看群聊的新图片调用选定生图 API，结果保存到聊天；重新打开聊天和查看大图不重复生图。历史描述卡可手动生成，失败明确提示，不暗中改用其他服务。开启后角色发图可能按服务商计费，请确认价格再使用；每次请求一张。

修复图片有描述却因缺少 image_prompt 无法生图的问题。开启通用生图后，模型遗漏或返回空白提示词时，直接使用这张图片的描述尝试生成；旧聊天中缺少提示词的图片也适用，不需要重新聊天，不额外调用主或副文字 API。

私聊、普通群聊和观看群聊统一补全并保存图片字段，回复提示要求同时提供画面描述与绘图提示词。保留关闭生图开关、真实图片预览和绘图服务失败提示；补全不代表第三方服务一定生成成功。

聊天明确付款但没说金额时，按前文单价、数量或商品参考估算，标记“估算支出”。特殊物品也可由本轮回复引用付款原文估价；不额外调用模型。角色钱包新增“校正金额”，按差额调整原账单，不重复扣款。

删除聊天同步撤销明确关联的收付款、调整原账户余额并清理提示；原转账/红包及领取记录联动。空间时间回到最后保留的消息，下一轮沿用该时刻。普通删除、彻底删除和总结段删除均支持；独立商城订单、其他聊天和手动/定期账单不误删。

若已花掉收款、回退后余额不足，会提示且保持原数据，不做半删。旧账单仅凭可核实来源关联，不按日期/金额猜测。删除不可恢复，重要数据请先备份。

主 API 的图片描述不等于实际生图；通用绘图和 NovelAI 使用各自服务。真实图片可点开预览；描述、未生成和绘图服务加载失败明确区分，不再用占位图冒充成功。

v1.7.75 的 API 预设更新按钮、主副 API 分工及完整记忆继续保留。
